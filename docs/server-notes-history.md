# UGlobalWeapon - Minecraft Plugin

![Minecraft](https://img.shields.io/badge/Minecraft-1.21%2B-blue?style=flat&logo=minecraft)
![Spigot](https://img.shields.io/badge/Spigot-API-ED8C1A?style=flat&logo=java)
![JDK 21](https://img.shields.io/badge/JDK-21-blue?style=flat&logo=java)

专为TensorPixel的UGlobal生存设计的武器系统插件，提供现代化武器和高级武器

## 武器行为

- 切换到 RPG 后会先播放 10 tick 抬枪动画（5 帧，每帧 2 tick）；动画完成前右键会被静默拦截，不消耗弹药、不发射也不显示提示。
- 抬枪模型使用固定位置和大小，从枪口朝下旋转到水平。工作区的 `UGlobalWeapon-client` 是可选 Fabric 1.21.1 客户端模组，用于关闭 RPG 的原版换手平移及模型换帧引发的重复动画；未安装模组仍可进服，但会保留原版客户端动作。服务器资源包不会自动安装客户端模组。
- 离枪动画已完全移除；切出武器使用原版物品栏切换，不取消事件、不延迟切换，也不强制设置栏位。
- RPG 射击方向会按蹲下、站立、行走、跑步使用不同散射角；数值集中在 `weapon/Gun.java` 的 `CONFIG` 中，单位为度，可按武器调整。
- 散射值表示圆锥半角，按立体角均匀采样；移动状态来自玩家实际水平位移，原地转头不计移动，停步后最多约 150ms 恢复站立精度。蹲下优先使用蹲姿精度，只有实际移动且处于疾跑状态时才使用跑步散射。
- 在工作区运行 `powershell -ExecutionPolicy Bypass -File .\tools\test-spread.ps1` 可执行散射回归检查（使用本地 JDK 21、Spigot API 与服务端依赖，无需下载测试框架）。
- RPG 导弹速度为 `RPG.PROJECTILE_SPEED`（1.65 格/tick），发射口和飞行轨迹都会生成烟雾粒子。
- RPG 冷却不再发送聊天提示：开火时出现闪光、扩散烟团和音效，随后枪口持续冒烟至冷却结束；切走武器时停止显示，切回且仍在冷却时恢复。
- RPG 已改为独立火箭弹显示实体与逐 tick 连续碰撞检测，不再生成火球。原先 200 tick 后删除、未加载区块删除的逻辑已移除；现在保留飞行所在区块，最长飞行 600 tick（约 30 秒、990 格），到达航程/世界边界时变为可回收弹药，不凭空消失。最多同时 64 发，结束后释放区块票据。
- 命中时主爆炸威力为原值的 1.1 倍（上限 18），随后第 4/8/12 tick 各发生一次主爆炸威力 40% 的二次爆炸。这些是真实爆炸，会伤害实体、破坏方块，不额外点火。
- 冲击波使用原版风弹阵风粒子、瞬时闪光和风爆音效，在 5 tick 内快速扩张并产生一次性径向击退；不再生成缓慢扩散的烟环。半径随型号变化（最多 24 格），力度随距离衰减并检查墙体遮挡。
- 二次爆炸结束后在可见地面生成最多 8 处真实残焰，约 6 秒后熄灭，阻止这些残焰向外蔓延；遵守点火事件取消。关闭插件时清理残焰。
- 客户端模组 1.0.2 提供 240ms 的轻微开火震屏，仅改变渲染相机，不修改玩家瞄准方向；资源包的枪械后坐力峰值降为 4 度。没有模组仍能看到服务端烟雾、尾焰和爆炸，但没有自定义震屏。

## 火箭弹与新模型

- 使用 `/uglobalweapon ammo 16` 获取专用火箭弹（1–64 发），`/uglobalweapon rpg normal` 获取火箭筒。每次成功发射消耗一发；普通火焰弹、普通海晶碎片不再作为弹药。
- 火箭弹是带专用标记和三维模型的物品，底层采用原版海晶碎片以兼容无模组客户端。右键实体方块顶面放置弹体，右键弹体取回；背包满时保留在地面。放置不点火、不爆炸，支撑方块被破坏后掉落弹药。
- 火箭筒使用军绿外壳、深灰护圈、黄色识别条、提把、瞄具、握把和散热槽；火箭弹具有弹头、尾翼和独立喷口。枪口烟随主手左右与朝向定位，飞行尾焰来自弹体尾部。
- 冷却期间炮管前半段整体（包括前护圈与外壳）呈红热、橙红、暗红、冷态四级变化，覆盖待机、抬枪、后坐力全部姿态。前半段沿管身多点冒烟；客户端 1.0.4 对这些热态表面提供轻微自发光，冷态关闭，后半段不发光。温度跟随现有的玩家共用 RPG 冷却；切走保留冷却，丢下武器时恢复冷态。
- 客户端 1.0.3 支持红热姿态中的后坐力识别。显示实体服务器跟踪上限调整为 512 格；实际画面可见距离仍取决于客户端渲染与服务器视距，超出视野不会停止弹道计算。
- 可编辑模型在工作区 `models/olive_launcher.bbmodel`、`models/rocket_round.bbmodel` 和 `models/weapon_design.blend`；`tools/modeling/build_models.py` 生成游戏资源与 Blockbench 文件，`tools/modeling/render_models.py` 用 Blender 生成场景和预览。
- 物品贴图必须使用可进入原版图集的 `textures/item/...` 路径；旧 `textures/palette/...` 路径会造成紫黑缺失纹理。打包脚本现在先检查原版图集规则、PNG 内容及热区覆盖范围，失败时不会覆盖下载包。

## 资源包

将项目根目录的 `UGlobalWeapon-Demo-ResourcePack.zip` 设置为服务器资源包，或解压到客户端资源包目录。资源包包含 RPG 的待机、抬枪和后坐力模型及 GUI/手持显示变换；没有资源包时物品仍可使用，但客户端只能显示原版下界之星图标。

当前演示资源包对应本地 Paper / Minecraft Java 1.21.1。RPG 使用 `elements` 定义三维模型，基础模型不能继承 `item/generated` 或 `item/handheld`：这些父模型使用二维贴图生成几何体，缺少 `layer0` 时会导致手持和物品栏都不可见。

客户端无需安装模组或预装资源包。服务器仅通过 `server.properties` 的 `resource-pack` 和 `resource-pack-sha1` 下发资源包；插件不再在加入后重复推送，避免旧 SHA-1 命中客户端缓存并覆盖正确模型。首次连接时接受服务器资源包，或在多人游戏的服务器设置中启用“服务器资源包”，即可自动下载和加载。`require-resource-pack=false` 允许拒绝资源包的玩家继续进入（此时只显示原版物品）。加载服务器资源时出现一次 Mojang 重载画面是正常行为。

修改资源后，在工作区根目录运行 `powershell -ExecutionPolicy Bypass -File .\build-resource-pack.ps1`，会重新生成两份 ZIP 并更新 `paper-server/server.properties` 中的 SHA-1。随后重启服务器并让客户端重新加入、接受服务器资源包；手动安装资源包的客户端需要替换 ZIP，再按 F3+T 重载。可用 `/uglobalweapon rpg normal` 获取 RPG 检查物品栏、手持、抬枪和射击动画。

本地资源包地址绑定 `127.0.0.1:8765`，仅适用于客户端和服务器在同一台电脑上的测试。其他电脑连接时需要使用客户端可访问的资源包托管地址。
